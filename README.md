# ✈️ Airline Reservation System

A full-stack Airline Reservation System developed using Flask and MySQL. The application allows users to search flights, book tickets, make payments, and manage reservations, while administrators can monitor bookings, revenue, customer analytics, and business reports through an interactive dashboard.

## Features

### User Module
- User Registration & Login
- Flight Search
- Flight Booking
- Seat Selection
- Payment Gateway
- Ticket & Invoice Generation (PDF)
- Booking History
- Upcoming Trips

### Admin Module
- Dashboard
- Airline Management
- Flight Management
- Route Management
- Schedule Management
- Booking Management
- Payment Management

### Analytics
- Revenue Analysis
- Booking Trend Analysis
- Occupancy Analysis
- Customer Analysis
- Flight Performance
- Route Performance
- SQL Reports
- CSV Export
- Power BI Dataset Export

## Tech Stack

- Python
- Flask
- MySQL
